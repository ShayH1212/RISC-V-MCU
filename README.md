# RISC-V-MCU
Custom RISC-V MCU designed in SystemVerilog

This project attempts to make custom RISK-V MCU in SystemVerilog to be printed and used to control the operation of a RC car.
The project aims to achieve this in 3 steps:
1. Create a simple single cycle CPU
2. Create a more complex multi-cycle CPU
3. Add necessary ports to turn the CPU into a MCU
